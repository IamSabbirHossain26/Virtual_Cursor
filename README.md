# This is a Virtual Hand Cursor

Control your mouse using hand gestures and a webcam without touching your physical mouse.

## 🖱️ Features of this tools
- Left Click (index + thumb pinch)
- Right Click (middle + thumb pinch)
- Drag & Drop (hold index + thumb)
- Scroll (move hand up/down)

## ▶️ How To Run this project on your local machine

```bash
pip install -r requirements.txt
python main.py
```

## 💡 Important Tip
Make sure your lighting is good for accurate tracking.
